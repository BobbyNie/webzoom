## 操作

1. 主持人开始共享，在参与者列表给同事“允许批注”。批注权和共享权分开管理。
2. 当前共享者点击“打开反馈小窗”。必须主动点击，不自动弹出。
3. 保持 WebZoom 标签页打开，切回 Excel、PPT 或其他共享窗口；在小窗里查看同事的画线和带姓名的指示光标。
4. “完整画面”显示本机共享预览及标注；“跟随指示 ×2”放大最近反馈区域；“仅标注”隐藏业务预览，仅显示位置示意和标注。
5. 关闭小窗不停止共享；可重新打开。停止共享、离开会议、共享权转交、登录失效或连接中断时关闭小窗。
6. 换页、滚动或改变业务内容后，先清除旧笔迹。本版不是跟随 Excel 单元格或文档对象的语义批注。

## 技术边界（不是桌面客户端）

- 使用浏览器的 Document Picture-in-Picture API，运行时检测能力。无安装包、插件、配对码或管理员安装要求，不提供远程鼠标控制。
- 要求可信 HTTPS 和支持该 API 的桌面浏览器，且公司策略允许。API 不可用或打开失败时明确提示；不拿普通弹窗冒充置顶窗口。
- 小窗内显示反馈，**不是把圈直接覆盖到原 Excel/PPT 窗口**。不承诺和原生会议客户端完全相同的桌面叠加效果。
- 复用当前共享 MediaStream 和已有的批注 WSS 消息，不新增媒体订阅连接、录制、音频、摄像头或业务文件上传。预览在本机显示，和远端实际解码存在网络时间差；额外本机渲染有资源开销。
- 整屏共享可能把置顶小窗也拍进去，造成重复画面。优先共享独立业务窗口/标签页，或把小窗移到未共享的第二块屏幕。“仅标注”移除递归视频预览，**不保证窗口本身不会被捕获**。网页不能可靠强制排除该窗口。
- 请求禁用浏览器共享期间的标签页切换入口（`surfaceSwitching: exclude`），只是浏览器提示，不是安全保证；切换共享来源应停止并重新共享，清理旧阶段批注。
- 笔迹、授权、限流及断线处理见 [ANNOTATIONS.md](ANNOTATIONS.md)。小窗不改变权限校验，不引入原生助手及相关服务端接口。
- 官方 API 说明：<https://developer.chrome.com/docs/web-platform/document-picture-in-picture>。最终以公司浏览器、窗口模式及策略实测为准。
