# 网页批注与观看体验升级（本地候选版）

版本标识：`annotation-dock-dev-20261027`。本文件描述当前分支代码，不表示已经发布镜像或部署到公司环境。仍是纯网页，不需要插件、EXE 或后台安装服务。现有屏幕传输、登录续期、浏览器分流路径保留。

## 使用方法

- 批注入口放在共享/结束会议同一底栏，所有视口默认收起。展开为紧凑图标条，鼠标悬停显示工具名称与快捷键；颜色与笔宽在“笔迹设置”，重做、清除、姓名及受策略控制的截图在“更多批注操作”。
- 不再提供画面内悬浮工具窗或拖动手柄；收起后画面内没有残留按钮/提示块。小屏工具图标横向滚动，整页不横向溢出。全屏也保留画面外的工具底栏，不以遮住共享画面换取空间。
- 收起工具栏或按 Esc 会退出绘画。展开不自动进入画笔，避免误画。
- **隐藏批注**仅对自己生效，其他人仍能看到；不会删除会议中的笔迹。共享者反馈小窗也有独立显示开关。
- 工具分组提供观看、画笔、署名指示光标、荧光笔、临时笔、直线、箭头、矩形、椭圆、文字和橡皮擦。文字最多 160 字，作为纯文本显示。
- 8 种颜色、4 档笔宽和笔迹预览。颜色、笔宽、姓名显示保存在当前浏览器本地（旧的工具栏位置不再使用）；不在本地保存会议内容、批注权限或待同步笔迹。
- **撤销/重做**只修改自己的内容；**橡皮擦**一次擦除自己的一整笔，也可撤销，不是像素橡皮。
- **清除我的**、主持人的**清除全部**需要确认，不能撤销。清除我的不会破坏别人的内容或撤销记录。主持人可一次收回所有批注权限，包括临时离线、尚在重连宽限期的参与者。
- **临时笔**按服务器时间从第一段笔迹起约 5 秒失效，不需另一人操作才能消失；后台浏览器可能延后重绘，但恢复显示时会过滤过期笔迹。撤销/重做不会使已过期临时笔复活。
- 姓名显示开关控制署名光标与短暂作者标签。笔迹始终在服务器按身份归属，不会因为隐藏姓名而改变权限。
- 观看设置提供专注观看（收起参与者面板）、100%～300% 缩放、放大后拖动画面、适应窗口。缩放/拖动只影响自己，笔迹仍用共享画面的归一化坐标同步。进入绘画工具会退出拖动画面。
- 状态提示区分连接中断、等待共享、画面接收及笔迹同步；同步确认较慢时限制积压，不能把未确认的笔迹当作已保存。

### 快捷键与触控

- `P`：画笔；`L`：指示光标；`E`：橡皮擦；`Esc`：退出绘画/关闭编辑或确认框。
- `Ctrl/⌘+Z`：撤销；`Ctrl+Y` 或 `Ctrl/⌘+Shift+Z`：重做。
- 输入框、下拉选择、文字输入法组合期间不拦截这些快捷键。确认框提供焦点循环和取消键。
- 绘画使用 Pointer Events，支持鼠标和触控；小屏提供较大点击目标。自动化测试覆盖桌面、小视口、全屏和多浏览器页面同步，不代表已经验证每一种实体触屏设备。

## 底栏交互边界

- 收起不会清除或自动隐藏笔迹；隐藏只影响自己，重新展开可恢复显示。
- 全屏的同步提示不改变画面高度，避免正在绘画时坐标跳动。颜色/更多选项主动展开时才占用额外的底栏空间。
- 从全屏点击“结束会议”先退出全屏，再显示原有确认框，不能直接结束或留下看不到的确认框。
- 这次修改不改变后端协议、批注授权、登录续期、分流调度或导出策略；未发布、未访问公司环境。

## 安全默认值：截图导出关闭

`ANNOTATION_EXPORT_ENABLED` 默认未设置/false，不显示保存按钮。仅服务器配置为精确值 `true` 后，经登录的网页可看到“保存截图”；导出前再次确认保存业务内容的权限。此配置不是管理员网页中的实时开关，生产启用应经过正常变更流程。

导出的是完整共享画面和已确认的当前可见笔迹，不是当前缩放裁剪；隐藏批注时导出无笔迹画面。指示光标、姓名标签和未确认草稿不导出。只在本机生成 PNG，不上传截图。此功能是产品层面的提示与默认策略，**不是 DRM**：无法阻止系统截图或开发者工具。

## 边界与运维说明

- 批注仍以共享会话为单位：重新共享/转交引起新共享后清空旧笔迹，不是跨会议白板或持久文档。
- 无法可靠识别共享者在外部应用中滚动、翻页或切换窗口。换页时可确认清除，短暂强调可用临时笔；不承诺自动跟随外部文档的文字位置。
- 每房间最多 128 个对象、8192 个点、单笔最多 512 个点，房间共享消息速率预算保持有界。为支持撤销，隐藏的历史对象也计入容量；达到上限后按提示清除自己的笔迹，或由主持人清除全部。界面自由笔在接近单笔上限时主动要求抬笔。
- 撤销、重做、擦除和清除会更新服务器版本，阻止旧分段复活。这类编辑可能取消另一端尚未确认的草稿，用户可重新绘制；已确认的其他人笔迹不会被自己的擦除/撤销删除。
- 批注消息继续走有身份校验的服务器同步，不借浏览器分流绕过授权。断线/收回授权会取消当前编辑；权限不能靠本地偏好恢复。
- 网页缩放、隐藏与专注观看不增加服务器视频复制路径，也不构成上百人容量验证。跨楼栋、外包网络、防火墙和实际人数仍需在批准的测试环境验收。
