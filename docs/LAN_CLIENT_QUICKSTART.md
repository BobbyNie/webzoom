# WebZoom 局域网分流：安装与使用

## 给使用者的一句话

需要 **Chrome 插件 + Windows 辅助程序**，两者各有分工：插件连接会议网页，辅助程序负责在同一局域网发送和接收广播。配套的 **WebZoom-LAN-Setup.exe** 是可以双击的安装与检查入口，不需要另装运行环境。

> 当前是未签名的开发候选版，还不是可直接面向公司全员发布的正式版本。标有“演示包”的 EXE 禁止安装和卸载，不会修改已有安装。不要为了安装而关闭安全软件或绕过公司的浏览器策略。

## 普通使用流程

1. 登录公司的 WebZoom 页面。页面自动检查插件与辅助程序；未就绪时直接显示 **下载 Windows 安装程序**，不需要每个同事访问 GitHub。安装包随服务端镜像进入内网。
2. 点击下载，打开 Chrome 的下载内容，运行 **WebZoom-LAN-Setup.exe**，选择 **安装 / 修复**。从本网站下载的包已经绑定网站及管理员配置的获批端口，不用同事手填。网页不能自动替人运行程序。
3. 安装 Chrome 插件：若 IT 已统一下发则跳过。获准的本机试点可点击安装器的 **打开扩展文件夹** 和 **打开 Chrome 扩展页**，在扩展页打开开发者模式，点击「加载已解压的扩展程序」并选择该文件夹。没有获准或策略不允许时，请 IT 统一下发，不绕过限制。EXE 安装辅助程序不等于已经装好插件。
4. 刷新 WebZoom。网页会自动做本机检查；通过后点击 **启用局域网分流**。这只检查本机，不发送广播，也不代表其他电脑已收到画面。处于 LAN 会议中时不会重复探测占用中的本地端口。
5. 三人试点：A 共享，B/C 同一获批局域网启用分流。B/C 应一台显示中继、一台显示接收，均看到 A 的动态画面；再测试中继离开后重选。角色自动选择，不需手工点选。

页面提示 `LAN_CLIENT_PORT` 未配置时，管理员统一配置一次已获批的端口后重启服务，同事不需要猜端口。旧的 GitHub 独立附件仍是现场配置模板，供 IT 使用；面向同事的入口是内网页面。

广播失败时会明确暂停并提示原因，**不会自动让所有参与者改成各自从服务器下载**。

## 遇到问题不用猜

- **尚未安装辅助程序**：运行 EXE；如果已安装，用同一份配套包修复。
- **端口不可用**：先退出其他 LAN 会议后重试。仍失败，请 IT 检查系统策略；不用自己改防火墙。
- **多个网卡 / VPN / 网卡变化**：请 IT 检查网卡选择，不要自行关闭公司 VPN。当前候选版尚不支持多 IPv4 网卡同时在线。
- **网站或版本不匹配**：用对应网站、同一份安装包更新插件和辅助程序。
- **本机检查通过但看不到广播画面**：仍可能是网络设备隔离广播。需要 IT 配合两台电脑现场测试；本机检查不会假报“广播已通过”。

## 修复与卸载

- 修复：退出 LAN 会议后，重新运行 EXE，点击 **安装 / 修复**。新版本写入独立目录，完整写入后才切换注册；不会覆盖仍在运行的旧程序。
- 卸载：退出所有 LAN 会议，运行同一 EXE，点击 **卸载**。程序仅移除自己的注册和已知文件；若文件仍被使用或目录里有额外文件，会明确提示保留，再次卸载可以重试。Chrome 扩展需按批准渠道单独移除。
- 安装范围：当前用户目录和当前用户的 Chrome 本地通信注册。没有系统服务、驱动或管理员权限请求，不更改防火墙、VPN、公司服务器及 Chrome 管理策略。

## 给 IT / 项目负责人的交付说明

安装前必须绑定**实际会议网站的 HTTPS 地址**与**获批的 UDP 端口**，不能把开发用 localhost 包发给公司用户。程序会展示这些值，安装时确认唯一 IPv4 网卡。

镜像内置的模板由服务端使用可信的 PUBLIC_URL 和 LAN_CLIENT_PORT 生成网站专用下载包，不采信请求的 Host / Forwarded 头，不需要运行时访问 GitHub。仅登录用户可下载；网站下载包的 SHA-256 在页面及响应头显示，其配置化后字节与原始模板不同。

独立 UAT 附件是可安装的现场配置包（不是 TestOnly 演示包），安装时填写这两个非秘密参数。空白配置不能安装；填写后只生成该网站的扩展配置与辅助程序策略，不授予所有网站权限。修复时预填本机已有配置。IT 也可使用 Build-LanClient.ps1 的 -Origin / -Port 生成固定配置包。不需要提供账号、密码、令牌或 SSO 密钥。上线前仍需通过双机真实广播、完整网页—插件—辅助程序链路、性能与出口带宽、标准用户安全策略及稳定性验收。完整记录见 LAN_RELAY_IMPLEMENTATION.md 与原有验收文档。

安装器内置校验用于发现文件损坏，**不是数字签名**。当前 EXE 尚未进行 Authenticode 签名；签名/受控分发必须由批准流程完成，当前封包器也尚未提供已签名安装包格式支持。
