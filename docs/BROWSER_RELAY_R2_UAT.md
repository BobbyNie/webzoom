# 网页分流 r2：逐人接收看板与一带三

日期：2026-10-16。分支：`feature/browser-peer-relay`。**已发布独立预发布镜像；尚未上传公司 JFrog 或更新公司 OCP。**

## 使用上有什么变化

所有人仍然只需网页登录、入会，不安装插件/EXE，不填写端口。主持人在共享前开启网页分流试验，开始共享后向下找到“全员接收情况”。

- 每行对应一个在线成员，包括共享者；显示真实登录姓名以及服务器安排的画面来源。
- “同伴：某某”表示当前被安排从该同事网页接收；“服务器 · 已安排向 N 人转发”表示转发节点的安排，不是 N 人已收到的确认。
- **同伴收流正常**：该接收端最近上报，本次供流安排确实收到通过签名与序号校验的画面，画面未超时。
- **服务器供流正常 / 已回退服务器**：接收端确认最近收到服务器画面；回退行附具体失败类别，不把超时直接归咎于防火墙。
- **画面暂未更新**：上报仍新鲜，但本次安排尚未收到帧，或最后的可验证画面已超过 4 秒。
- **等待供流**：当前没有可用节点/供流额度；不能称为分流成功。
- **等待接收端上报**：本次安排没有报告，流量显示“—”，不是收到 0 的确认。
- **上报中断，状态待确认**：超过 8 秒未刷新，不以历史收到过的字节继续显示绿色。
- 表格可上下滚动；窄屏可左右滑动查看流量。观众只看本机信息，不能收到主持人专用的全员看板。

本机三个数字明确区分“从服务器接收”“从同伴接收（已验证）”“向同伴发送”。累计范围是各自本次页面连接；重新安排时累计值保留，但“本次安排已验证帧数”重新计算。发送包含分片头，与对方已验证完整帧的字节不要求完全相等，不能把发送计数当对方接收确认。

报告由已登录浏览器自行上报；服务端按真实连接绑定身份，限制数字范围、单调累计、报告速率和当前安排代次。报告不是独立审计，也不保证帧已在对方屏幕渲染，更不能相加等同公司出口节省量。

## 人数与供流策略

- 服务端总开关 `BROWSER_RELAY_ENABLED` 保持默认关闭；已开启的公司配置仍需按发布手册保留。
- `BROWSER_RELAY_MAX_VIEWERS=32` 是默认观众上限，不含一位共享者。允许 1–64，非法配置启动失败；不是要普通同事填写。
- 取消旧的第五人拒绝逻辑，超出配置上限仍明确拒绝。既有负载测试人数限制（若主动开启）仍独立生效。
- 一个转发层，每个节点最多带三位观众（不含转发者自己）；人数变多自动增加节点。正常 4 位观众是 1 个服务器供流节点 + 3 个同伴接收者，5 位观众是 2 个服务器供流节点 + 3 个同伴接收者。
- 每条中心画面流按原有 8 Mbps 预留（包含共享者上传），所有会议共用带宽限制。新增节点、失败回源和节点退出恢复都不能绕过限额；不足者等待，不无条件全部回源。
- 保留健康节点，不承诺退出后总能压缩到理论最少节点数。当前不是多层转发树，不自动判断办公室/VLAN/地理位置，不新增公网 STUN/TURN。

## 公司怎么简单验证（部署新镜像后）

1. 主持人共享一份不断变化的画面，让 4 位观众分别用自己的账号加入（共 5 人）：正常情况下是 1 位转发者 + 3 位同伴接收者。看转发者一行显示“已安排向 3 人转发”，并确认三位接收者都有接收量增长；再加入第 5 位观众验证新增节点。网络不可达或中心额度不足时，以实际回退/等待状态为准。
2. 主持人看“全员接收情况”：有人的来源为“同伴：某某”，状态为“同伴收流正常”，“从同伴接收”持续增长，说明该观众实际有同伴供流。首次由同伴供流的观众应没有服务器画面累计值；若之前回源过则累计数不归零。
3. 让不同楼的同事也加入。若显示服务器回退，他能看画面不等于跨楼分流成功；记录该行原因，不按距离推断网络可达。
4. 让一个转发节点离会，观察其他人的重新安排与恢复。允许短暂等待；预算不足须显示等待，不能偷偷全量回源。
5. 连续 10 分钟观察画面、接收量、CPU/上传与恢复时间。服务端上限不等于已经过容量压测。

## 本轮本机验证

- 前端：40 个单测通过，类型检查和生产构建通过。
- 既有浏览器回归：62/62 通过（小窗、批注、SSO/续期、普通会议等）。
- 分流浏览器联测：5/5 通过，使用真实本机 DataChannel，包括五会话三下游、节点退出恢复、受阻后有/无预算回退、六会话五观众中途入会、主持人逐人上报、观众隔离、390px 窄屏不撑破页面，以及报告中断/恢复。
- 服务端：正式模块单测和静态检查通过；32 观众拓扑 8 节点 + 24 同伴、64 观众拓扑 16 节点 + 48 同伴均通过，预算、扇出、人数、报告身份和旧代次隔离有测试。
- Windows 运行排除了既有 `TestFileStoreInitialConfigurationAndRestart`（POSIX 文件权限差异）；未修改/删减该测试。Linux 全量 race/vet、安全扫描、镜像及部署测试必须在发布前通过，不能把 Windows 本机结果当完整发布证据。
- 真实浏览器是同一电脑上的隔离会话，不是六台公司电脑；没有实际核验跨楼网络、32/64 台电脑容量或公司出口节流率。
