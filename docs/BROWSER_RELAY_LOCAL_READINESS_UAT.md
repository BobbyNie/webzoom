### 清理两项检查阻塞

1. `internal/bandwidth/store_test.go` 原来要求文件权限严格等于 `0660`。Windows 的 Go `os.Chmod` 只支持通过 owner-writable 位控制只读标记，不提供 Unix 组/其他用户权限语义。测试现在检查 `os.Stat` 错误；Windows 检查文件仍可写，Linux/Unix 保留精确 `0660` 断言。持久化、重启读取、覆盖、损坏及临时文件清理检查没有跳过，生产存储代码没有因此放宽。
2. 被 Git 忽略的旧 `artifacts/sep-site-diagnostic/main.go` 属于另一条本地诊断工作，引用当前分支没有的 `internal/lansetup`。没有删除或修改这些旧诊断，也没有把原生 UDP 分支合入。只在本地忽略目录新增 `artifacts/go.mod`，建立独立模块边界，让根模块的 `./...` 保持只检查应用源码。`artifacts` 中没有 Git 跟踪的应用源码；干净 CI 检出也不含这些旧诊断。该本地模块边界不是提交到产品中的代码修复，更不是使旧诊断恢复可编译。

## 六观众 15 分钟原生长测：连通通过，流畅性未通过

2026-10-21 本地时间 `16:03:57` 开始；完整用例 `999.499 秒`，其中真实连续共享 `904.646 秒`（15 分 4 秒）。本轮长测的后端尚为升级前的 Go 1.26.9；安全修正后的后端回归另行计时，不把它说成重新完成了同样的长测。

使用已安装 Chrome `155.0.8059.39`、Edge `155.0.4283.62`，1 个共享者、6 个独立浏览器观众，真实 `getDisplayMedia` 采集专用动态 DOM 标签页。没有以 Canvas 生成流替换屏幕采集，也不采集业务窗口或音频。

### 防止同类“假绿”

长测结束后新增 `enduranceQuality.ts`：按约 60 秒分段检查每位观众，足够长的尾段也检查；高动态 fixture 默认设 `15 fps` 最低测试保护线，持续低于保护线的观众不能被整体平均掩盖。这个保护线只是回归测试门槛，不是已经商定的业务性能 SLA。故障恢复和资源清理仍先完成，再报告流畅性断言失败。

新增 5 项单测验证后段塌陷、单个慢观众、尾段、短暂停顿、采样不足与无效数据。用本次真实样本离线重算，新保护线正确返回 `passed: false`，最低分段 `0.952 fps`，证据为 `native-endurance-quality-replay.json`。**这是对原始数据的离线重算，不是再跑一次真实 15 分钟，更没有宣称长测问题已修复。**

后续长测还会逐次记录源页更新计数、可见性与焦点，以区分源动画/浏览器调度、原生采集和后续媒体链路。本次只有源页全程平均更新 `112.57 Hz`，缺少末段源更新分段数据，无法据此断言是应用内存泄漏、浏览器节流、系统调度或测试源停慢。没有为了获得通过结果而关闭系统锁屏、安全策略、休眠或修改企业浏览器策略。

### 内存与资源观察

仅通过 CDP 查询这些隔离测试浏览器报告的进程 ID，再读取相应 Windows 内存和句柄计数；没有枚举或监控其他应用。

| 样本 | 起始 | 连续期峰值 | 连续结束 | 最后停止后 |
|---|---:|---:|---:|---:|
| 已采样浏览器进程 Private Bytes 合计（MiB） | 4422 | 5159 | 2497 | 4194 |
| Working Set 合计（MiB） | 6282 | 7279 | 5396 | 438 |
| 共享控制页 + 六观众 JS 已用堆合计（MiB） | 59.88 | 59.88 | 33.29 | 36.24 |

- 启动后进程从 54 个收敛到 47 个，稳定期保持 47 个，计数采样均覆盖 CDP 当次报告的进程；故障时替换浏览器另计。
- 稳定期页面 DOM 节点数收敛到 2132，没有逐次采样不断上升；最后停止后为 1963。
- 全程可用系统内存样本为 `504–3807 MiB`。早期有明显内存压力，后段也有帧率塌陷；现有证据不足以认定二者因果关系。
- Working Set 会受到共享页、Windows 驻留/裁剪影响；Private Bytes、JS 堆和显存不是同一种指标。停止后 Private Bytes 并未随 Working Set 同步下降，不能把后者降到 438 MiB 当作所有视频资源已经释放的证明。JS 指标不包含独立源页 JS 堆，但进程汇总包含 CDP 报告的源页进程；也没有测量 GPU 显存。
- 没有强制 GC、清空缓存或把内存差异包装成“无泄漏证明”。15 分钟结果只能说明本次采样变化，不能替代更长时间或多物理设备验证。
