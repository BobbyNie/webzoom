# 批注专属矢量图标验收（2026-10-28）

## 目的和范围

替换批注工具原有的 Unicode 字符图标，尤其区分鼠标观看、指示光标和绘制箭头。采用项目内绘制的 SVG，而非字体图标、外部图标服务或生成式位图；小尺寸保持清晰，颜色随按钮状态变化，无新增第三方依赖或网络请求。

- 新组件 `web/src/AnnotationIcon.tsx`：18 个图标，24×24 统一坐标，通常显示为 20×20。
- 观看：带尾部的实心鼠标指针；指示光标：圆形靶心；箭头：长杆开放箭头。
- 重画画笔、荧光笔、临时笔（笔+时钟）、直线、矩形、圆形、文字、橡皮擦、撤销、眼睛/划线眼睛、更多、展开/收起、关闭。
- 共享画面中的带姓名指示光标也使用矢量鼠标，保留发送者颜色，加入白色阴影以改善复杂画面上的辨认。指针尖端对齐发送的坐标。
- 保留按钮可访问名称、用途提示、快捷键、选中/禁用状态；图标本身不单独朗读或接收焦点。
- 保留底栏、默认折叠、手机横向滚动和全屏布局。不改变批注消息、权限或分流协议。
